Verificar Hash (SHA-256)

hash original

Este é o hash que o remetente divulgou junto com a mensagem ou o arquivo (o que foi gerado na tela 1). Cole o hash, carregue o arquivo .sha256 ou use o último hash gerado.

dados recebidos

Agora informe a mensagem ou o arquivo que você recebeu. O hash será calculado de novo e comparado com o esperado. Para simular uma alteração, mude uma letra da mensagem ou use outro arquivo.

O hash dos dados recebidos é calculado e comparado, caractere por caractere, com o hash esperado.

  • O hash garante a integridade: se os dados mudarem, mesmo que 1 bit, o hash muda.
  • O hash não é criptografia: não existe "decifrar" um hash. É uma função de mão única.
  • O hash sozinho não garante quem enviou: um atacante poderia trocar o arquivo e o hash juntos. Para provar a autoria, usamos a assinatura digital, que é o próximo assunto.
  • Usos comuns: conferir downloads, armazenar senhas (com sal), blockchain e assinatura digital.
